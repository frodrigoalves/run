# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Netlify deployment

For a static export deployment on Netlify:

- Set the build command to `npm run build`.
- Configure the publish directory to `out` (the folder generated by `next build`).
- No Next.js-specific Netlify plugin is required for this static setup.
